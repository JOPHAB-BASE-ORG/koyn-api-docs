This guide takes you from nothing to a successful authenticated call against the Koyn API.

## Prerequisites

- A Koyn account (mobile) or a staff account (admin console).
- An HTTP client such as curl, Postman or the built-in playground on any endpoint page.

## Get started

<Steps>
  <Step title="Pick a base URL">
    Production requests go to `https://api.getkoyn.com/api`. See [Environments](/guides/environments) for staging and local URLs.
  </Step>
  <Step title="Obtain a token">
    Mobile clients call [Login](/api-reference/mobile/authentication/login-passwords/login). Staff call [Console login](/api-reference/admin/auth/login). Both return a Sanctum bearer token.

    ```bash
    curl -X POST https://api.getkoyn.com/api/login \
      -H "Content-Type: application/json" \
      -H "X-Client-Version: 2.0.2" \
      -d '{"email": "you@example.com", "password": "your-password"}'
    ```
  </Step>
  <Step title="Call an authenticated endpoint">
    Send the token in the `Authorization` header.

    ```bash
    curl https://api.getkoyn.com/api/wallet/balance \
      -H "Authorization: Bearer YOUR_TOKEN" \
      -H "Accept: application/json"
    ```
  </Step>
  <Step title="Try it in the playground">
    Open any endpoint page, click **Try it**, paste the token into the authorization field and send the request.
  </Step>
</Steps>
