title: "Mobile API overview"
description: "Endpoints consumed by the Koyn mobile app."
---

Endpoints consumed by the Koyn mobile app, covering registration, wallet, crypto, bills, gift cards and account management.

Registration, login and password reset are open; every other route requires a user bearer token from login, passed as `Authorization: Bearer <token>`. App routes also pass through a client-version gate, so requests carry the app version. Responses use the standard `{ success, message, data }` envelope. See [Authentication](/guides/authentication), [Environments](/guides/environments) and [Responses](/guides/responses).

<Note>
  Example payloads are captured responses with personal data masked. Confirm each page against the current Laravel routes before relying on it.
</Note>
