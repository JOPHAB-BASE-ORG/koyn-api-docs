## How it works

This returns the currencies the swap provider currently supports, so you can build a swap picker. The response is a plain array under `data` with no pagination. The provider decides the shape returned, so treat entries defensively: `data` may be a list of ticker strings or a list of objects with `name`, `fullName`, `ticker` and `image`.

<ResponseExample>

```json 200
{
  "success": true,
  "message": "successful",
  "data": [
    "btc",
    "eth"
  ]
}
```

```json 200 (2)
{
  "success": true,
  "message": "successful",
  "data": [
    {
      "name": "XDC",
      "fullName": "XinFin Network",
      "ticker": "xdc",
      "image": "https://cdn.changelly.com/icons/xdc.png"
    },
    {
      "name": "DOGE",
      "fullName": "Dogecoin",
      "ticker": "doge",
      "image": "https://cdn.changelly.com/icons/doge.png"
    }
  ]
}
```

</ResponseExample>
