title: "Send Feedback"
api: "POST /feedback"
---

## How it works

You send a support message, which is queued as an email to the support inbox. This endpoint is public (no authentication) and does not validate the body, so it forwards whatever fields you submit. Send at least a subject and body, and an email so support can reply.

## Body

<ParamField body="subject" type="string">
   Example: `Sample Subject`
</ParamField>

<ParamField body="body" type="string">
   Example: `Hi, just wanted to report an issue.`
</ParamField>

<ParamField body="email" type="string">
   Reply-to email address. Example: `user@example.com`
</ParamField>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "Successfully sent your message",
  "data": []
}
```

</ResponseExample>
