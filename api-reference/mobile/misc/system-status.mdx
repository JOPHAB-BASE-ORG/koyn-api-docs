## How it works

You get the platform's operational flags, one per subsystem (for example `withdrawal` and `bill_payment`). Each entry's `value` shows whether that feature is currently enabled, with an optional `message`. This endpoint is public, takes no parameters, and returns a plain array under `data` (no pagination).

```json 200
{
  "success": true,
  "message": "System status",
  "data": [

      "id": 2,

      "message": "We are active",
      "created_at": null,

  ]
}
```

</ResponseExample>
