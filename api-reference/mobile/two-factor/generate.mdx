## Get Crypto Wallet

Retrieves the user's crypto wallet details for a specific asset.

**Method:** `GET`  
**Path:** `{{domain}}/api/crypto/wallets/:asset`

### Authentication
Requires valid authentication token in the Authorization header.

### Request Headers
- `Authorization: Bearer {{token}}`

### Path Variables
- `asset` - The cryptocurrency asset symbol (e.g., "BTC", "ETH", "USDT")

### Response Format
```json
{
  "success": true,
  "data": {
    "wallet": {
      "asset": "BTC",
      "address": "bc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh",
      "balance": "0.00123456",
      "network": "Bitcoin",
      "created_at": "2024-01-01T12:00:00Z"
    }
  }
}
```

### Notes
- Returns wallet address and balance for the specified asset
- Wallet must be created before it can be retrieved
- Use the Create Wallet endpoint if wallet doesn't exist
