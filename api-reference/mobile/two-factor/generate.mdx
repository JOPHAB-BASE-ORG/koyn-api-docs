---
title: "Generate"
api: "POST /two-factor/generate"
---

## How it works

This generates a 6-digit two-factor code for the authenticated user, tied to a specific operation (for example a withdrawal), and emails it. If a valid code for that operation already exists and `isResend` is not set, the existing code stands and a new one is not generated. Any prior codes for the operation are cleared before a new one is issued, and each code expires after 5 minutes. Requires a valid bearer token. This endpoint returns a plain `{ message }` body rather than the standard response envelope.

## Body

<ParamField body="operation" type="string" required>
  The action the code authorises. Example: `withdrawal`
</ParamField>

<ParamField body="verificationOptions" type="object" required>
  Details of the operation being verified. Example: `{ "amount": 1000, "bankAccountID": 32 }`
</ParamField>

<ParamField body="isResend" type="boolean">
  Set to `true` to force a new code even if a valid one already exists.
</ParamField>

<RequestExample>

```json Request
{
  "operation": "withdrawal",
  "verificationOptions": {
    "amount": 1000,
    "bankAccountID": 32,
    "platform": "MOBILE",
    "datetime": "2019-08-24T14:15:22Z"
  },
  "isResend": true
}
```

</RequestExample>

<ResponseExample>

```json 200
{
  "message": "Verification code sent successfully."
}
```

```json 200 Already sent
{
  "message": "A valid verification code has already been sent to your email."
}
```

</ResponseExample>
