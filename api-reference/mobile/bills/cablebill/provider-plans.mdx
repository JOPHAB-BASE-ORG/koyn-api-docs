---
title: "Provider Plans"
api: "GET /cable/plans/{provider}"
---

List the plans for a cable provider. Each plan carries the `code` you pass to the purchase endpoint. The `data` array is not paginated. See [Response envelope](/guides/responses) for the standard `{ success, message, data }` shape.

## Path parameters

<ParamField path="provider" type="string" required>
   Example: `Dstv`
</ParamField>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "successful",
  "data": [
    {
      "name": "Nova",
      "code": "900",
      "amount": "900"
    },
    {
      "name": "Basic",
      "code": "1300",
      "amount": "1300"
    }
  ]
}
```

```text Example
{
  name: string
  code: string
  amount: string
}
```

</ResponseExample>
