## How it works

This debits your wallet (naira balance) for the plan and queues the cable subscription with the provider. Verify the smartcard first to obtain the `customer_name`. Your account must be active and unflagged, the request must come from a verified device, and the `bills` service switch must be on, or the request is rejected with `409`; it also fails when your balance is insufficient or a matching purchase is already in flight.

## Body

<ParamField body="product" type="string" required>
  Cable product code, for example `StarTimes`. Must match an active provider.
</ParamField>

<ParamField body="code" type="string" required>
  Plan code from the provider plans endpoint. Example: `900`
</ParamField>

<ParamField body="smart_card_no" type="string" required>
  Smartcard / IUC number, digits only. Example: `0000000000`
</ParamField>

<ParamField body="customer_name" type="string" required>
  Account holder name returned by smartcard verification. Example: `JOHN DOE`
</ParamField>
