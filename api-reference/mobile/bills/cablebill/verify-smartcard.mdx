---
title: "Verify smartcard"
api: "POST /cable/smartcard/verify"
---

## How it works

This calls the provider to look up the smartcard and returns the account details so you can confirm the holder before you purchase. Show the returned `customer_name` to the user and pass it to the purchase endpoint. If the card cannot be found or the provider is unreachable, the request fails with `409`.

## Body

<ParamField body="product" type="string" required>
  Cable product code, for example `StarTimes`. Must match an active provider.
</ParamField>

<ParamField body="smart_card_no" type="string" required>
  Smartcard / IUC number, digits only. Example: `0000000000`
</ParamField>

<RequestExample>

```json Request
{
  "product": "StarTimes",
  "smart_card_no": "0000000000"
}
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "successful",
  "data": {
    "product": "STARTIMES",
    "customer_name": "MICHEAL OLUGHU",
    "customer_no": "0004044606",
    "customer_type": 1,
    "smart_card_no": "0000000000",
    "balance": "1912.92"
  }
}
```

```text Example
{
```

</ResponseExample>
