---
title: "Data plans"
api: "GET /phonebill/data-plans/{network}"
---

List the data plans for a network. Each plan carries the `code` you pass to the purchase endpoint. The `data` array is not paginated. See [Response envelope](/guides/responses) for the standard `{ success, message, data }` shape.

## Path parameters

<ParamField path="network" type="string" required>
   Example: `MTN`
</ParamField>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "Plans",
  "data": [
    {
      "name": "50MB 1 DAY",
      "code": "3000",
      "amount": "100"
    },
    {
      "name": "200MB 1 DAY",
      "code": "3001",
      "amount": "200"
    }
  ]
}
```

```text Example
{
  name: string
  code: string
  amount: string
}
```

</ResponseExample>
