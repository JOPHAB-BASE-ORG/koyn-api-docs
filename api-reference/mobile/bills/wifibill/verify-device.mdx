---
title: "Verify device"
api: "POST /wifi/device/verify"
---

## How it works

This calls the provider to look up the device and returns the account details so you can confirm the holder before you purchase. Show the returned `customer_name` to the user and pass it to the purchase endpoint. If the device cannot be found or the provider is unreachable, the request fails with `409`.

## Body

<ParamField body="product" type="string" required>
  One of `Smile` or `Spectranet`.
</ParamField>

<ParamField body="device_no" type="string" required>
  Device / modem number, digits only. Example: `0000000000`
</ParamField>

<RequestExample>

```json Request
{
  "product": "Smile",
  "device_no": "0000000000"
}
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "successful",
  "data": {
    "product": "SMILE",
    "customer_name": "JERAHMEEL ANIBOR",
    "device_no": "0000000000"
  }
}
```

```text Example
{
  product: string
  customer_name: string
  device_no: string
}
```

</ResponseExample>
