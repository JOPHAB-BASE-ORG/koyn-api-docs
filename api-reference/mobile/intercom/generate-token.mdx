---
title: "Generate token"
api: "POST /intercom/generate-token"
---

## How it works

You generate Intercom authentication data for the authenticated user, including a signed JWT and the identity-verification `user_hash` used for Intercom secure mode. The `platform` tailors the response to the calling client. It defaults to `web` when omitted.

## Body

<ParamField body="platform" type="string" default="web">
  Client platform. One of `web`, `android`, `ios`. Example: `web`
</ParamField>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "JWT token generated successfully",
  "data": {

    "platform": "web",

  }

```

</ResponseExample>
