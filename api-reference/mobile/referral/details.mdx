## How it works

You get the authenticated user's referral summary: their `referral_code`, total earnings, amount already redeemed, amount still available to claim, total number of referrals, and how many of those referrals are `eligible_referrals` (referred users who have reached the 200 trade-volume threshold). It takes no parameters.

<ResponseExample>

```json 200
{
  "success": true,
  "message": "successful",
  "data": {
    "referral_code": "9IveAy",
    "referral_amount_available": 0,
    "referral_amount_redeemed": 0,
    "total_referral_earnings": 0,
    "eligible_referrals": 0,
    "total_referrals": 0
  }
}
```

</ResponseExample>
