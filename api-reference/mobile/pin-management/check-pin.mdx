---
title: "Check Pin"
api: "POST /pin/verify"
---

## How it works

This confirms that a supplied 4-digit PIN matches the authenticated user's stored transaction PIN. Use it to gate a sensitive action before proceeding. Requires a valid bearer token. It returns success only when the PIN is correct.

## Body

<ParamField body="pin" type="string" required>
  4-digit transaction PIN to verify. Example: `0000`
</ParamField>

<RequestExample>

```json Request
{
  "pin": "0000"
}
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "Pin checked successfully.",
  "data": null
}
```

</ResponseExample>
