## How it works

This completes the password reset flow. You submit the email, the OTP that was emailed by `POST /password/reset-request`, and the new password. The endpoint verifies the OTP is still valid, updates the password, and clears any failed login attempts on the account. The route is rate-limited (`throttle:login`) and protected by Turnstile, so a valid bot-protection token may be required.

## Body

<ParamField body="email" type="string" required>
  Registered email address. Example: `user@example.com`
</ParamField>

<ParamField body="token" type="string" required>
  Numeric OTP sent to the email. Example: `0000`
</ParamField>

<ParamField body="password" type="string" required>
  New password. Minimum 8 characters, with upper and lower case letters and at least one number. Example: `**********`
</ParamField>

<RequestExample>

```json Request
{
  "email": "user@example.com",
  "token": "0000",
  "password": "**********"
}
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "password updated successfully.",
  "data": null
}
```

</ResponseExample>
