---

## How it works

This starts the password reset flow by emailing a one-time OTP to the account. The email must belong to an existing user. The route is rate-limited (`throttle:login`) and protected by Turnstile, so a valid bot-protection token may be required. Confirm the OTP and set the new password with the `PUT /password/reset` endpoint.

## Body

<ParamField body="email" type="string" required>
  Registered email address. Must match an existing account. Example: `user@example.com`
</ParamField>

<RequestExample>

```json Request
{
  "email": "user@example.com"
}
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "One time password for otp reset has been sent.",
  "data": null
}
```

</ResponseExample>
