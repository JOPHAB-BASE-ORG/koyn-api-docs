## How it works

Step 5 submits the full profile and creates the account. It re-validates the email, phone, and password together, creates the user and their wallet, and credits the signup bonus. A valid referral code, if supplied, is recorded and may award an additional bonus. On success the endpoint returns a Sanctum bearer token and the new user object, logging the user straight in. This step is protected by Turnstile, so a valid bot-protection token may be required.

## Body

<ParamField body="name" type="string">
  Optional full name. Example: `David Logic`
</ParamField>

<ParamField body="email" type="string" required>
  Email address. Must be unique and use an accepted domain. Example: `user@example.com`
</ParamField>

<ParamField body="phone" type="string" required>
  Phone number. Exactly 11 digits and unique. Example: `08012345678`
</ParamField>

<ParamField body="password" type="string" required>
  Password. Minimum 8 characters, with upper and lower case letters and at least one number. Example: `**********`
</ParamField>

<ParamField body="heard_about_us" type="string">
  Optional. How the user found Koyn. Maximum 255 characters.
</ParamField>

<ParamField body="referral_code" type="string">
  Optional referral code. Must be an active code if provided. Example: `LOGIC100`
</ParamField>

<ParamField body="avatar" type="string">
  Optional avatar URL.
</ParamField>
