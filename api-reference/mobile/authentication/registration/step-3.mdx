## How it works

Step 3 validates the phone number. It must be exactly 11 digits and unique across accounts. This step is protected by Turnstile, so a valid bot-protection token may be required. The value is echoed back so the client can carry it into the final step.

## Body

<ParamField body="phone" type="string" required>
  Phone number. Exactly 11 digits and unique. Example: `08012345678`
</ParamField>

<RequestExample>

```json Request
{
  "phone": "08012345678"
}
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "successful",
  "data": {
    "phone": "08012345678"
  }
}
```

</ResponseExample>
