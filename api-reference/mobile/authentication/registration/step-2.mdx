## How it works

Step 2 verifies the email by checking the OTP that step 1 sent. You submit the email and the numeric token; the endpoint confirms the token matches and has not expired. This step is protected by Turnstile, so a valid bot-protection token may be required.

## Body

<ParamField body="email" type="string" required>
  Email address the OTP was sent to. Example: `user@example.com`
</ParamField>

<ParamField body="token" type="string" required>
  Numeric verification OTP. Example: `0000`
</ParamField>

<RequestExample>

```json Request
{
  "email": "user@example.com",
  "token": "0000"
}
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "email verified successfully",
  "data": []
}
```

</ResponseExample>
