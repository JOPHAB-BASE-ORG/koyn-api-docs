## How it works

Registration proceeds step by step against `POST /register/step/{step}`, where `{step}` is `step-1` through `step-5`. The whole flow is protected by Turnstile, so a valid bot-protection token may be required. Step 1 validates the email and emails a verification OTP to it; the email must be unique and use an accepted domain (`gmail.com`, `outlook.com`, `yahoo.com`, `getkoyn.com`, or `icloud.com`).

## Body

<ParamField body="name" type="string">
  Optional full name. Example: `David logic`
</ParamField>

<ParamField body="email" type="string" required>
  Email address. Must be unique and use an accepted domain. Example: `user@example.com`
</ParamField>

<RequestExample>

```json Request
{
  "name": "David logic",
  "email": "user@example.com"
}
```

</RequestExample>

<ResponseExample>

```json 200
{
```
