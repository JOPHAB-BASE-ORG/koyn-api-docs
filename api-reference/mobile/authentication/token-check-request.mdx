---
title: "Token check Request"
api: "POST /check-token"
---

## How it works

This confirms that an OTP sent to an email is still valid before you proceed. You submit the email and the numeric OTP, and the endpoint checks it against the stored, unexpired token. Use it to verify a code during password or PIN reset flows without consuming it.

## Body

<ParamField body="email" type="string" required>
  Email address the OTP was sent to. Example: `user@example.com`
</ParamField>

<ParamField body="token" type="string" required>
  Numeric OTP to verify. Example: `0000`
</ParamField>

<RequestExample>

```json Request
{
  "email": "user@example.com",
  "token": "0000"
}
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "One time password checked successfully.",
  "data": null
}
```

</ResponseExample>
