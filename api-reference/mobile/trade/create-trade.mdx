title: "Create Trade"
api: "POST /trades"

This allows the creation of a new giftcard trade transaction with the provided parameters. It expects the following data to be submitted in the request body:

###### Body

- `card_id` (integer): The ID of the card associated with the trade.
- `value` (decimal): The value or amount of the trade.
- image (file): The array of images for the trade
- `payment_method` (optional, string): The selected payment method for the trade, such as
    - **Allowed Values**: `NGN`, `USDT Address`
- address: The USDT address to be credited if the selected payment method is USDT Address
- `e_code` (optional, string): An additional code or identifier related to the trade, if applicable.
