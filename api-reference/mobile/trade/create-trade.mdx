<Warning>
  This endpoint belongs to the retired gift card trade flow and is no longer served. Use the current gift card trade endpoint, `POST /giftcards/trades`, instead.
</Warning>

## How it works

You submit a gift card for sale against a legacy `giftcards` record. You must supply either an `e_code` or one or more `images` (each satisfies the other's `required_without` rule). The `payout_method` selects where the payout lands (naira wallet or USDT). On success the created trade is returned under a `trade` key.

## Body

<Note>Send as `multipart/form-data`.</Note>

<ParamField body="giftcard_id" type="integer" required>
  The `id` of an existing `giftcards` record. Example: `12`
</ParamField>

<ParamField body="amount" type="number" required>
  Card value to sell. Between `5` and `5000`. Example: `10`
</ParamField>

<ParamField body="payout_method" type="string" required>
  Where the payout is credited. One of `NGN`, `USDT`. Example: `NGN`
</ParamField>

<ParamField body="e_code" type="string">
  Gift card e-code. Required when no images are sent. Example: `ASD123`
</ParamField>

<ParamField body="images[]" type="file">
  Card image(s), each `jpeg`, `png`, or `jpg`, up to 20 MB. Required when no `e_code` is sent.
</ParamField>

<ResponseExample>

```json 201
{
  "trade": {}
}
```

</ResponseExample>
