---
title: "Wallet Balance"
api: "GET /wallet/balance"
---

## How it works

This returns just your wallet's naira `balance` and when it last changed, for a lightweight refresh. It reads your own wallet from the bearer token, so it takes no parameters. For the full wallet record use [Wallet details](/api-reference/mobile/wallet/wallet-details).

## Headers

<ParamField header="X-Client-Version" type="string">
Example: `2.0.2`
</ParamField>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "Wallet balance fetched successfully",
  "data": {
    "balance": "44000.00",
    "updated_at": "2024-04-25T08:35:02.000000Z"
  }
}
```

```text Example
{

  updated_at: string|DateTime
```

</ResponseExample>
