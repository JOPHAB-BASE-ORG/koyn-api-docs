---
title: "Update password"
api: "PUT /change-password"
---

## How it works

You change the authenticated user's account password. The `old_password` must match the current password, the new `password` must be confirmed by `password_confirmation`, and the new password must differ from the current one. The response returns the updated user record.

## Body

<ParamField body="old_password" type="string" required>
  The user's current password. Example: `**********`
</ParamField>

<ParamField body="password" type="string" required>
  The new password. Must differ from the current password. Example: `**********`
</ParamField>

<ParamField body="password_confirmation" type="string" required>
  Must match `password`. Example: `**********`
</ParamField>

<RequestExample>

```json Request
{
  "old_password": "**********",
  "password": "**********",
  "password_confirmation": "**********"
}
```
