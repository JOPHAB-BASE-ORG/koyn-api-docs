---
title: "Profile Edit"
api: "POST /profile/edit"
---

## How it works

You update the authenticated user's profile. All fields are optional; send only what you want to change. A submitted `username` is lowercased before saving, must be unique, and cannot be a reserved name. The response returns the refreshed user record.

## Body

<ParamField body="phone" type="string">
  Nigerian phone number. Exactly 11 digits and unique across users. Example: `08012345678`
</ParamField>

<ParamField body="username" type="string">
  3–20 characters, letters, digits, underscore or hyphen only (`^[a-zA-Z0-9_\-]+$`). Must be unique and not a reserved username. Example: `logicfx`
</ParamField>

<ParamField body="avatar" type="string">
  Avatar image URL. Example: `https://res.cloudinary.com/diyxzs220/image/upload/v1721761303/avatar/php1YUbSQ_fneksr.jpg`
</ParamField>
