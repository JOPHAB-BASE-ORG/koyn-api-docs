## How it works

This saves a payout bank account to your profile. Pick a `bank_id` from the [operating banks](/api-reference/mobile/banking/operating-banks) list; the bank name, code and logo are resolved from it automatically. You can hold at most 5 accounts, and the same account number cannot be added twice — either rejects the request with a validation error. Your first saved account is automatically set as primary.

## Body

<ParamField body="bank_id" type="number" required>
  Id of the operating bank, from the banks list. Example: `2`
</ParamField>

<ParamField body="account_name" type="string" required>
  Account holder name. Example: `afuwape sunday`
</ParamField>

<ParamField body="account_number" type="string" required>
  10-digit account number. Example: `0000000000`
</ParamField>
