---
title: "Delete account V2"
api: "DELETE /bank/v2/{bank}/delete"
---

## How it works

This is the OTP-protected version of removing a saved payout bank account. Pass the account id in the path and a valid 6-digit `code` generated for the `delete_bank` operation; an invalid or expired code fails validation, and the code is consumed before the account is removed. It only deletes an account that belongs to you (`404` otherwise), returns `409` if removal fails, and returns `null` in `data` on success.

## Path parameters

<ParamField path="bank" type="number" required>
  Id of your saved bank account to remove. Example: `556`
</ParamField>

## Body

<ParamField body="code" type="string" required>
  6-digit OTP generated for the `delete_bank` operation. Example: `123456`
</ParamField>

<RequestExample>

```json Request
{
  "code": "123456"
}
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "Bank removed successfully.",
  "data": null
}
```

</ResponseExample>
