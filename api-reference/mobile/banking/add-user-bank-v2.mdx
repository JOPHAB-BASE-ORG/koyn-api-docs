## Get All Bank Accounts

Retrieves all bank accounts associated with the authenticated user.

**Method:** `GET`  
**Path:** `{{domain}}/api/banks`

### Authentication
Requires valid authentication token in the Authorization header.

### Request Headers
- `Authorization: Bearer {{token}}`

### Response Format
```json
{
  "success": true,
  "data": {
    "banks": [
      {
        "id": "uuid",
        "account_number": "0212700896",
        "account_name": "John Doe",
        "bank_name": "Bank Name",
        "bank_code": "619",
        "bank_logo": "https://example.com/logo.png",
        "primary": true,
        "created_at": "2024-01-01T12:00:00Z"
      }
    ]
  }
}
```

### Notes
- Returns all saved bank accounts
- Primary account is flagged for easy identification
- Empty array returned if no accounts exist
