## How it works

This is the OTP-protected version of adding a payout bank account. It behaves like [Add user Bank](/api-reference/mobile/banking/add-user-bank) — resolving bank details from `bank_id`, enforcing the 5-account limit, rejecting duplicates, and marking your first account primary — but also requires a valid 6-digit `code` generated for the `add_bank` operation. An invalid or expired code fails validation, and the code is consumed once the account is saved.

## Body

<ParamField body="bank_id" type="number" required>
  Id of the operating bank, from the banks list. Example: `2`
</ParamField>

<ParamField body="account_name" type="string" required>
  Account holder name. Example: `afuwape sunday`
</ParamField>

<ParamField body="account_number" type="string" required>
  10-digit account number. Example: `0000000000`
</ParamField>

<ParamField body="code" type="string" required>
  6-digit OTP generated for the `add_bank` operation. Example: `123456`
</ParamField>
