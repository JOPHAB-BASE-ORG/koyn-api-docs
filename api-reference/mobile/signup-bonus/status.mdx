## How it works

You get the authenticated user's signup bonus progress. When a bonus exists, `has_bonus` is `true` and `bonus` reports the amount, the required and current trade volume, progress percentage, whether it `can_claim`, and unlock and claim timestamps. When no bonus applies, `has_bonus` is `false`. It takes no parameters.

<ResponseExample>

```json 200
{
  "success": true,
  "message": "successful",
  "data": {
    "has_bonus": true,
    "bonus": {
      "status": "pending",
      "bonus_amount": "500.00",
      "required_trade_volume": "200.00",
      "current_trade_volume": "0.00",
      "progress_percentage": 0,
      "remaining_trade_volume": 200,
      "can_claim": false,
      "unlocked_at": null,
      "claimed_at": null
    }
  }
}
```

</ResponseExample>
