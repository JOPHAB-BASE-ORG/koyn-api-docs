## How it works

Monnify calls this route with the result of a disbursement (payout) it processed for Koyn, such as a `SUCCESSFUL_DISBURSEMENT` event. The route is exempt from the client-version gate. Koyn acknowledges receipt and hands the event to a queued job that updates the matching withdrawal's status.
