## How it works

Redbiller calls this route with the result of a bank transfer (payout) it processed for Koyn. Redbiller publishes no callback signature, so the payload is treated as untrusted: before acting, Koyn re-queries the transaction directly at Redbiller. The route is exempt from the client-version gate. Koyn acknowledges receipt and hands the event to a queued job that updates the matching withdrawal's status.
