Inbound callbacks from payment, KYC and crypto infrastructure providers. These are called by the provider, not by Koyn clients, so the playground is disabled.

All paths are relative to the environment base URL. See [Environments](/guides/environments) and [Authentication](/guides/authentication).

<Note>
  This reference was migrated from the Koyn Postman collection. Example payloads are captured responses with personal data masked. Confirm each page against the current Laravel routes before relying on it.
</Note>
