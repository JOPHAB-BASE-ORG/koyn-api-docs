## How it works

Returns the published crypto-to-naira conversion rate bands shown on the marketing site. Each band maps a USD value range to the rate applied. This endpoint needs no authentication and is exempt from the client-version gate.

<ResponseExample>

{
  id: string
  rate_range: string
  rate: int|float
  range_start": int|float
  range_end: int|float
  is_published": true
}
