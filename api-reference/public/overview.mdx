Unauthenticated endpoints under `front/crypto` that expose crypto assets and conversion rates for the marketing site.

These routes need no authentication and are exempt from the client-version gate, so any client can call them without a token or version header. Responses use the standard `{ success, message, data }` envelope. See [Responses](/guides/responses) for the envelope, and [Environments](/guides/environments) for base URLs.

<Note>
  Example payloads are captured responses with personal data masked. Confirm each page against the current Laravel routes before relying on it.
</Note>
