---
title: "Create Rejection"
api: "POST /console/rejection-reasons"
---

## How it works

Saves a new rejection reason template. The reason is stored with type `withdrawal` so it is available when declining withdrawals. Requires the `rejection_templates.manage` console ability.

## Body

<ParamField body="reason" type="string" required>
  The rejection reason text staff can later reuse.
</ParamField>

<RequestExample>

```json Request
{
  "reason": "Hey fella thats wrong"
}
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "successful",
  "data": {
    "reason": "Hey fella thats wrong",
    "type": "withdrawal",
    "updated_at": "2024-08-17T21:13:07.000000Z",
    "created_at": "2024-08-17T21:13:07.000000Z",
    "id": 11
  }
}
```

</ResponseExample>
