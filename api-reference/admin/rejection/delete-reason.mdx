---
title: "Delete Reason"
api: "DELETE /console/rejection-reasons/{rejectionReason}"
---

## How it works

Permanently deletes a rejection reason template so staff can no longer select it. Requires the `rejection_templates.manage` console ability.

## Path parameters

<ParamField path="rejectionReason" type="string" required>
   ID of the rejection reason to delete.
</ParamField>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "Reason deleted successfully",
  "data": []
}
```

</ResponseExample>
