---
title: "Update rejection"
api: "PATCH /console/rejection-reasons/{rejectionReason}"
---

## How it works

Updates the text of an existing rejection reason template. Requires the `rejection_templates.manage` console ability.

## Path parameters

<ParamField path="rejectionReason" type="string" required>
   ID of the rejection reason to update.
</ParamField>

## Body

<ParamField body="reason" type="string">
  Replacement rejection reason text.
</ParamField>

<RequestExample>

```json Request
{
  "reason": "Hmm thats wrong"
}
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "successful",
  "data": {
    "reason": "Hey fella thats wrong",
    "type": "withdrawal",
    "updated_at": "2024-08-17T21:13:07.000000Z",
    "created_at": "2024-08-17T21:13:07.000000Z",
    "id": 11
  }
}
```

</ResponseExample>
