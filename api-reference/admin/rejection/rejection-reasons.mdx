## How it works

Returns the catalogue of saved rejection reason templates, latest first. Staff select one of these when declining a withdrawal or KYC request. Reading the list requires either the `withdrawals.manage` or the `kycs.manage` console ability.

## Query parameters

<ParamField query="type" type="string">
  Filter the list to a specific reason type. Pass `withdrawal` to return only withdrawal rejection reasons.
</ParamField>
