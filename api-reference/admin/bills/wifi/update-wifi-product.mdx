---
title: "Update Wifi Product"
api: "POST /console/wifi/products/{id}"
---

## How it works

Updates one WiFi provider by id and returns the saved record. Send the body as `multipart/form-data`. Omit `logo` to keep the current image, or attach a new image to replace it. Requires a staff bearer token with the `bill_products.manage` ability; a request without it returns `403`.

## Path parameters

<ParamField path="id" type="string" required>
   Example: `1`
</ParamField>

## Body

<Note>Send as `multipart/form-data`.</Note>

<ParamField body="product" type="string" required>
   Provider name. Example: `Spectranet`
</ParamField>

<ParamField body="status" type="string" required>
  Provider state. Example: `active`
</ParamField>

<ParamField body="logo" type="file">

</ParamField>
