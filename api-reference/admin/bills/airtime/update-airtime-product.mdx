---
title: "Update Airtime product"
api: "POST /console/airtime/products/{id}"
---

## How it works

Updates one airtime product by id and returns the saved record. Send the body as `multipart/form-data`. Omit `logo` to keep the current image, or attach a new image to replace it. Requires a staff bearer token with the `bill_products.manage` ability; a request without it returns `403`.

## Path parameters

<ParamField path="id" type="string" required>
   Example: `1`
</ParamField>

## Body

<Note>Send as `multipart/form-data`.</Note>

<ParamField body="product" type="string" required>
   Product name. Example: `MTN`
</ParamField>

<ParamField body="status" type="string" required>
  Product state. Example: `active`
</ParamField>

<ParamField body="maximum_amount" type="number">
   Optional. Example: `5000`
</ParamField>

<ParamField body="minimum_amount" type="number">
   Optional. Example: `200`
</ParamField>

<ParamField body="logo" type="file">

</ParamField>
