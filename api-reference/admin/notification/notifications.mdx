title: "Notifications"
api: "GET /console/notification"
---

## How it works

Lists previously-sent notification bulletins, newest first, with per-bulletin delivery counts (`successful`, `failed`). Results come back as a Laravel paginator — see [Response envelope](/guides/responses). Requires the `notifications.manage` console ability.

## Query parameters

<ParamField query="per_page" type="integer">
  Records per page. Defaults to `25`.
</ParamField>
