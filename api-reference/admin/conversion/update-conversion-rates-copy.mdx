---
title: "Delete Conversion Rate"
api: "DELETE /console/conversion-rate/{id}"
---

## How it works

Deletes a conversion rate band. Requires a staff bearer token with the `crypto_rates.manage` ability. Requests without it return `403`.

## Path parameters

<ParamField path="id" type="string" required>
  Conversion rate id. Example: `9c62d58d-4d0c-4fb3-8554-2825d723dac7`
</ParamField>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "Rate deleted successfully",
  "data": []
}
```

</ResponseExample>
