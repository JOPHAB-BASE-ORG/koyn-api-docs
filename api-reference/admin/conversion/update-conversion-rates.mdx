---
title: "Update Conversion Rates"
api: "PUT /console/conversion-rate/{id}"
---

## How it works

Updates an existing conversion rate band and returns the updated record. Send only the fields you want to change. Requires a staff bearer token with the `crypto_rates.manage` ability. Requests without it return `403`.

## Path parameters

<ParamField path="id" type="string" required>
  Conversion rate id. Example: `9c62d58d-4d0c-4fb3-8554-2825d723dac7`
</ParamField>

## Body

<ParamField body="rate_range" type="string">
  Human-readable label for the band. Example: `Below $50k`
</ParamField>

<ParamField body="rate" type="number">
  Naira rate applied to this band. Example: `1900`
</ParamField>

<ParamField body="fee" type="number">
  Percentage fee for this band. Example: `1.5`
</ParamField>

<ParamField body="range_start" type="number">
  Lower USD bound of the band. Example: `1000`
</ParamField>

<ParamField body="range_end" type="number">
  Upper USD bound of the band. Example: `50000`
</ParamField>

<ParamField body="is_published" type="boolean">
  Whether the band is live. Example: `true`
</ParamField>
