## How it works

Returns the platform feature switches as a plain array of status rows. Each row has a `key`, a boolean `value` (on or off), and an optional `message`. When a switch is off, its gated routes are blocked. The current keys are:

- `withdrawal` — wallet withdrawals
- `bills` — mobile bill payments (airtime, data, cable, meter, betting, wifi)
- `crypto_deposit` — crypto wallet creation and deposits
- `general_message` — a general platform notice

<Note>The `bills` key is the live bill-payments switch that mobile bill routes gate on. The older `bill_payment` key is being retired; use `bills`.</Note>

Requires a staff bearer token with the `settings.manage` ability. Requests without it return `403`.
