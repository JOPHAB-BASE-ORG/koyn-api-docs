---
title: "Low balance status"
api: "GET /console/redbiller/low-balance"
---

## How it works

Checks the float balance held at the active withdrawal gateway (Redbiller, or Nomba when it is the active gateway) and reports whether it has fallen below the configured low-balance threshold. This route is financially sensitive: it has no ability catalogue entry and requires a full-access staff account. Requests from other staff return `403`.

<ResponseExample>

```json 200
{
  "success": true,
  "message": "successful",
  "data": {
    "low": false,
    "provider": "REDBILLER",
    "provider_balance": 1250000.0
  }
}
```

</ResponseExample>
