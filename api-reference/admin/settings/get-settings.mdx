title: "Get settings"
api: "GET /console/settings"

## How it works

Returns every system setting as a plain array of `key`/`value` rows (payment gateway, withdrawal mode, automatic withdrawal limit, sweep address, and related keys). Requires a staff bearer token with the `settings.manage` ability. Requests without it return `403`.

<ResponseExample>

{
  "success": true,
  "message": "successful",
  "data": [
    {
      "id": 1,
      "key": "payment_gateway",

}

</ResponseExample>
