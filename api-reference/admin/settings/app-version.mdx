## How it works

Returns the recorded mobile app versions. The mobile app compares its build against these to decide whether to prompt or force an update. Requires a staff bearer token with the `settings.manage` ability. Requests without it return `403`.

<ResponseExample>

```json 200
{
  "success": true,
  "message": "Minimum app version",
  "data": [
    {
      "id": 2,
      "version_number": "1.0",
      "release_date": "2024-06-01",
      "message": "Good people version",
      "created_at": "2024-06-27T05:57:08.000000Z",
      "updated_at": "2024-06-27T05:57:08.000000Z"
    }
  ]
}
```

</ResponseExample>
