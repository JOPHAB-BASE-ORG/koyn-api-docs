---
title: "Staff Fulfilled"
api: "GET /console/withdrawals/employee/{id}"
---

## How it works

Returns the withdrawals settled by a given staff member, as a Laravel paginator with each record's `user` and the settling `settled_by` staff embedded. See [Responses](/guides/responses) for the paginator shape. Requires the `withdrawals.manage` console ability.

## Path parameters

<ParamField path="id" type="string" required>
  The staff member's user id (`userId`).
</ParamField>
