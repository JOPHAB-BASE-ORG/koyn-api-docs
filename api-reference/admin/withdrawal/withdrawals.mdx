## How it works

Returns withdrawal (payout) requests as a Laravel paginator, with each record's `user` embedded and an `overview` object summarising counts by status (successful, pending, rejected). See [Responses](/guides/responses) for the paginator shape. Requires the `withdrawals.read` console ability.

Payouts are restricted to a bank account whose name matches the user's verified BVN government-data name; the check runs at request time, on [approval](/api-reference/admin/withdrawal/approve), and immediately before the queued payout. When an already-queued payout fails the check, no transfer is sent: it is returned to manual review and `ownership_check_reason` carries the failure reason. This field is admin-only — it is omitted from customer-facing responses.
