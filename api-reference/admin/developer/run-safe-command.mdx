---
title: "Run Safe Command"
api: "POST /console/developer/artisan"
---

## How it works

Runs one pre-approved maintenance command from the console. Only bare command names on the allowlist are accepted: `optimize:clear`, `cache:clear`, `config:clear`, `route:clear`, `view:clear`, `app:unflag-users` and `report:duplicate-emails`. Any whitespace or arguments are rejected with a `422`, and a command outside the allowlist returns `403`. On success the command name and its output are returned. Requires the `developer.manage` console ability.

## Body

<ParamField body="command" type="string" required>
  The exact allowlisted command to run, with no arguments.
</ParamField>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "Command executed successfully.",
  "data": {
    "command": "app:unflag-users",
    "output": "No flagged users found.\n"
  }
}
```

</ResponseExample>
