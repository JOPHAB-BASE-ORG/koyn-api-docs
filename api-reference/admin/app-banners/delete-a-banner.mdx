---
title: "Delete a banner."
api: "DELETE /console/app-banners/{app_banner}"
---

## How it works

Permanently deletes an app banner by its id. Requires the `banners.manage` console ability.

## Path parameters

<ParamField path="app_banner" type="string" required>
  The banner id. Example: `9e00db7f-bd60-4f68-af1c-c6c21396a236`
</ParamField>

<ResponseExample>

```json 200
{
  "success": true,
  "message": "App Banner deleted successfully",
  "data": []
}
```

</ResponseExample>
