title: "Held Deposits"
api: "GET /console/crypto/deposits/held"

## How it works

Lists Vaultody deposits the webhook refused to credit automatically and parked for manual review — because the deposited asset did not match the resolved wallet (e.g. USDT sent to an ETH-only address), the address is shared by more than one user, or a stablecoin was mispriced. Returns a Laravel paginator. Requires the `deposits.read` console ability.

### Query parameters

<ParamField query="status" type="string" default="held">
  `held` (default) or `dismissed`.
</ParamField>
<ParamField query="per_page" type="integer" default="20">
  Items per page, 1–100.
</ParamField>

Each item includes the `reason` it was held, the on-chain details, `wallets_at_address` (every wallet on that address with its owning user), and the reviewer fields once actioned.
