## How it works

Returns users' crypto swap transactions, with each user embedded under `user`. The `data` object is a Laravel paginator (`current_page`, `last_page`, `per_page`, `*_page_url`) and carries an `overview` count of successful and pending swaps. See [Response envelope](/guides/responses). Requires a staff bearer token with the `swaps.read` ability. Requests without it return `403`.
