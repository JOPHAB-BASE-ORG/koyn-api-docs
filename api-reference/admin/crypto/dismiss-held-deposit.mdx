---
title: "Dismiss Held Deposit"
api: "POST /console/crypto/deposits/held/{id}/dismiss"
---

## How it works

Closes a held deposit without crediting it — for deposits settled manually (e.g. via `deposit:recredit`), refused, or identified as fraud. Only `held` deposits can be dismissed. A note is **required**. Requires the `deposits.manage` console ability, and writes an admin activity-log entry.

<ParamField path="id" type="integer" required>
  The held deposit (webhook event) id.
</ParamField>
<ParamField body="note" type="string" required>
  Reason for dismissing, max 1000 characters.
</ParamField>
