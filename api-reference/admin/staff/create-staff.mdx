---
title: "Create Staff"
api: "POST /console/staffs/create"
---

## How it works

Creates a staff account and assigns it a console role. The email must not already belong to another account, the password is hashed on save, and the new account is stored with `user_type` set to `staff`. Requires the `staffs.manage` console ability.

## Body

<ParamField body="name" type="string" required>
  Staff member's full name (max 200 characters).
</ParamField>

<ParamField body="email" type="string" required>
  Login email. Must be unique across accounts.
</ParamField>

<ParamField body="role" type="string" required>
  Console role. One of `accountant`, `announcer`, `marketer`, `support`, `cs_support`.
</ParamField>

<ParamField body="password" type="string" required>
  Initial account password.
</ParamField>
