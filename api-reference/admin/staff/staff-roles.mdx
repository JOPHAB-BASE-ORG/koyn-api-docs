title: "Staff Roles"
api: "GET /console/staffs/roles"
---

## How it works

Returns the catalogue of console roles you can assign to staff accounts. Use it to populate the role selector when creating or updating staff. Requires the `staffs.manage` console ability.

<ResponseExample>

```json 200
{
  "success": true,
  "message": "successful",
  "data": [
    {
      "id": 1,
      "name": "accountant"
    },
    {
      "id": 2,
      "name": "announcer"
    }
  ]
}
```

</ResponseExample>
