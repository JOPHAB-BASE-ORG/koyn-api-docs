## How it works

Returns user counts grouped by how each account first heard about Koyn. Known sources (Twitter, Instagram, Google, From a Friend, Snapchat and TikTok) are reported individually, and everything else is grouped under `Other`. Requires the `dashboard.read` console ability.

<ResponseExample>

```json 200 Overview Copy
{
  "success": true,
  "message": "successful",
  "data": [
    {
      "heard_about_us": "Google",
      "total": 29
    },
    {
      "heard_about_us": "Twitter",
      "total": 1
    }
  ]
}
```

</ResponseExample>
