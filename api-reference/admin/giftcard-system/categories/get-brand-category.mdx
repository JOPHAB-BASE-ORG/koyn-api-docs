---
title: "Get Brand Category"
api: "GET /console/giftcards/categories/{giftcardCategoryV2}"
---

## How it works

Returns a single gift card category with its parent brand.

Requires a staff bearer token with the `giftcards.manage` ability. Requests without it return `403`.

## Path parameters

<ParamField path="giftcardCategoryV2" type="integer" required>
  Category ID. Example: `1`
</ParamField>
