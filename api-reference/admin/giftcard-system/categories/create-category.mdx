---
title: "Create Category"
api: "POST /console/giftcards/categories"
---

## How it works

Creates a category under a brand (for example, "USA e-code" under iTunes). A category carries the trade `min`/`max` face value and the `rate` used to value trades. If you omit `position`, the category is appended to the end of the brand's ordered list; a supplied `position` inserts it there and the brand's other categories are renumbered so positions stay contiguous.

Requires a staff bearer token with the `giftcards.manage` ability. Requests without it return `403`.

## Body

<ParamField body="brand_id" type="integer" required>
  ID of the brand this category belongs to. Must reference an existing brand. Example: `1`
</ParamField>

<ParamField body="name" type="string" required>
  Category name. Max 255 characters. Example: `USA ECODE 🇱🇷`
</ParamField>

<ParamField body="min" type="number" required>
  Minimum face value accepted for a trade. Must be `0` or greater. Example: `20`
</ParamField>

<ParamField body="max" type="number" required>
  Maximum face value accepted for a trade. Must be greater than or equal to `min`. Example: `99`
</ParamField>

<ParamField body="rate" type="number" required>
  Payout rate applied to the traded amount. Must be `0` or greater. Example: `1300`
</ParamField>

<ParamField body="position" type="integer">
  1-based position within the brand's category list. Defaults to the end of the list.
</ParamField>

<ParamField body="is_active" type="boolean">
  Whether the category is shown to app users. Example: `1`
</ParamField>

<ParamField body="requires_receipt" type="boolean">
  Whether users must attach a receipt image when trading this category. Example: `0`
</ParamField>
