---
title: "Update GiftCard Category"
api: "PUT /console/giftcards/categories/{giftcardCategoryV2}"
---

## How it works

Updates a gift card category. Every field is optional, so send only what you are changing. Fields go in the request body. If the resulting `max` would be below `min`, the request is rejected with `422`. Changing `position`, or moving the category to a different `brand_id`, renumbers the affected brands so positions stay contiguous.

Requires a staff bearer token with the `giftcards.manage` ability. Requests without it return `403`.

## Path parameters

<ParamField path="giftcardCategoryV2" type="integer" required>
  Category ID. Example: `1`
</ParamField>

## Body

<ParamField body="brand_id" type="integer">
  Move the category to another brand. Must reference an existing brand.
</ParamField>

<ParamField body="name" type="string">
  Category name. Max 255 characters.
</ParamField>

<ParamField body="min" type="number">
  Minimum face value. Must be `0` or greater.
</ParamField>

<ParamField body="max" type="number">
  Maximum face value. Must be `0` or greater and not below `min`.
</ParamField>

<ParamField body="rate" type="number">
  Payout rate. Must be `0` or greater.
</ParamField>

<ParamField body="position" type="integer">
  1-based position within the brand's category list.
</ParamField>

<ParamField body="is_active" type="boolean">
  Whether the category is shown to app users.
</ParamField>

<ParamField body="requires_receipt" type="boolean">
  Whether users must attach a receipt image. Example: `1`
</ParamField>
