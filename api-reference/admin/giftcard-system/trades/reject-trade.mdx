---
title: "Reject Trade"
api: "POST /console/giftcards/trades/{giftcardTrade}/reject"
---

## How it works

Rejects a pending or processing trade. The trade is marked `rejected`, `reviewed_at` is stamped, `rejected_by` records the reviewing staff, and the underlying wallet transaction is set to rejected so no wallet credit is made. The user is notified with the comment. A trade that is already approved or rejected returns `409`.

Requires a staff bearer token with the `giftcards.manage` ability. Requests without it return `403`.

## Path parameters

<ParamField path="giftcardTrade" type="integer" required>
  Trade ID. Example: `2`
</ParamField>

## Body

<ParamField body="admin_comments" type="string">
  Reason shown to the user and stored on the trade. Optional; defaults to `Rejected.` Max 2000 characters. Example: `The Giftcard image is not shown`
</ParamField>
