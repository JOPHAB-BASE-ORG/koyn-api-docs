---
title: "Approve Trade"
api: "POST /console/giftcards/trades/{giftcardTrade}/approve"
---

## How it works

Approves a pending or processing trade and routes it through the chosen fulfilment `vendor`. The user's wallet is credited with `amount × rate` (either value can be overridden here), the trade is marked `approved`, `reviewed_at` is stamped, and `approved_by` records the reviewing staff. The approved volume also feeds the user's signup bonus and referral milestone, and the user is notified. A trade that is already approved or rejected returns `409`.

Requires a staff bearer token with the `giftcards.manage` ability. Requests without it return `403`.

## Path parameters

<ParamField path="giftcardTrade" type="integer" required>
  Trade ID. Example: `1`
</ParamField>

## Body

<ParamField body="vendor" type="string" required>
  Fulfilment vendor the approved trade is routed through. One of `TIGER`, `TEAM FU`, `WP 1131`, `TIANHE`, `SKYGC`, `WY`, `JOE & DEAN`. Example: `TIGER`
</ParamField>

<ParamField body="rate" type="number">
  Override the payout rate before crediting. Must be `0` or greater. Defaults to the trade's stored rate. Example: `1000`
</ParamField>

<ParamField body="amount" type="number">
  Override the traded face value before crediting. Must be `0` or greater. Defaults to the trade's stored amount.
</ParamField>

<ParamField body="admin_comments" type="string">
  Optional note stored on the trade. Max 2000 characters. Example: `Due to rate change, your credit was reduced`
</ParamField>
