---
title: "Create brand"
api: "POST /console/giftcards/brands"
---

## Body

<Note>Send as `multipart/form-data`.</Note>

<ParamField body="name" type="string">
  Name of the brand Example: `iTunes`
</ParamField>

<ParamField body="logo" type="file">
  a logo of the brand
</ParamField>

<ParamField body="is_active" type="string">
  Display brand to live users Example: `1`
</ParamField>

<ResponseExample>
