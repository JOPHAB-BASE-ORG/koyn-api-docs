title: "Crypto Swaps"
api: "GET /console/users/{id}/swaps"
---

## How it works

Returns a user's crypto swap history, newest first. Each row records the swap provider reference, type, status, source and destination currencies, expected amounts, and network fee. The list is a Laravel paginator (Form A: `data.data[]` with `current_page`, `last_page`, page URLs) — see [Responses and errors](/guides/responses).

Requires a staff bearer token with the `users.read` or `users.manage` ability. Requests without either return `403`.

## Path parameters

<ParamField path="id" type="string" required>
  User ID. Example: `41`
</ParamField>
