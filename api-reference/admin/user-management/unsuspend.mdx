---
title: "Unsuspend"
api: "POST /console/users/{userId}/unsuspend"
---

## How it works

Restores a suspended user by setting its status back to `active` and notifies the user by email. No request body is needed.

Requires a staff bearer token with the `users.manage` ability. Requests without it return `403`.

## Path parameters

<ParamField path="userId" type="string" required>
   Example: `9ca7f3e5-4811-492c-a8ea-68821808ed96`
</ParamField>
