title: "Crypto Deposits"
api: "GET /console/users/{id}/deposits"
---

## How it works

Returns a user's crypto deposit history, newest first. Each row records the crypto asset, on-chain amount, conversion rate, naira payout, confirmations, status, and transaction hash. The list is a Laravel paginator (Form A: `data.data[]` with `current_page`, `last_page`, page URLs) — see [Responses and errors](/guides/responses).

Requires a staff bearer token with the `users.read` or `users.manage` ability. Requests without either return `403`.

## Path parameters

<ParamField path="id" type="string" required>
  User ID. Example: `1163`
</ParamField>
