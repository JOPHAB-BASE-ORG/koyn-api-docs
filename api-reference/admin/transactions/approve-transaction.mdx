---
title: "Approve Trade"
api: "POST /console/giftcards/trades/{id}/approve"
---

## How it works

Approves a pending or processing gift card trade, assigns the vendor it was fulfilled through, marks it `approved`, and credits the user's wallet with `amount * rate`. Optional `rate` and `amount` override the trade's stored values before crediting. A trade that is already processed returns `409`. Requires a staff bearer token with the `giftcards.manage` ability. Requests without it return `403`.

## Path parameters

<ParamField path="id" type="string" required>
  Gift card trade id. Example: `10`
</ParamField>

## Body

<ParamField body="vendor" type="string" required>
  Vendor the trade was fulfilled through. One of the supported trade vendors: `TIGER`, `TEAM FU`, `WP 1131`, `TIANHE`, `SKYGC`, `WY`, `JOE & DEAN`.
</ParamField>

<ParamField body="rate" type="number">
  Override the trade rate before crediting. Minimum `0`. Example: `1500`
</ParamField>

<ParamField body="amount" type="number">
  Override the trade amount before crediting. Minimum `0`. Example: `100`
</ParamField>

<ParamField body="admin_comments" type="string">
  Optional internal note. Max 2000 characters. Example: `Verified and approved`
</ParamField>
