---
title: "Get Employee Transactions"
---

<Warning>
  This endpoint is no longer part of the console API. There is no per-employee gift card trade listing; browse trades through `GET /console/giftcards/trades` (requires the `giftcards.read` ability), which returns each trade's reviewer under the `approved_by` and `rejected_by` relations. For a staff member's wallet withdrawals, use `GET /console/withdrawals/employee/{userId}` (requires the `withdrawals.manage` ability).
</Warning>
