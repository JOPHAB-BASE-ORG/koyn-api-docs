---
title: "Get One Trade"
api: "GET /console/giftcards/trades/{id}"
---

## How it works

Returns a single gift card trade with its `user`, `brand`, `category`, and reviewer relations. Requires a staff bearer token with the `giftcards.read` ability. Requests without it return `403`.

## Path parameters

<ParamField path="id" type="string" required>
  Gift card trade id. Example: `355`
</ParamField>
