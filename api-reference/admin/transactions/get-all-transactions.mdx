---
title: "Get All Trades"
api: "GET /console/giftcards/trades"
---

## How it works

Returns gift card trades, newest first, with each trade's `user`, `brand`, `category`, and reviewer relations embedded. The `data` object uses the custom pagination form (`data`, `total`, `per_page`, `current_page`, `total_pages`), not the Laravel paginator. See [Response envelope](/guides/responses). Requires a staff bearer token with the `giftcards.read` ability. Requests without it return `403`.

## Query parameters

<ParamField query="status" type="string">
  Filter by trade status. Example: `pending`
</ParamField>

<ParamField query="search" type="string">
  Match by trade id, code, reference, or the user's name or email. Max 255 characters. Example: `user@example.com`
</ParamField>

<ParamField query="brand_id" type="integer">
  Filter by gift card brand. Example: `4`
</ParamField>

<ParamField query="category_id" type="integer">
  Filter by gift card category. Example: `12`
</ParamField>

<ParamField query="date_from" type="string">
  Include trades created on or after this date. Example: `2025-01-01`
</ParamField>

<ParamField query="date_to" type="string">
  Include trades created on or before this date. Must be on or after `date_from`. Example: `2025-01-31`
</ParamField>

<ParamField query="has_code" type="boolean">
  Filter to trades that have (or lack) a code. Example: `true`
</ParamField>

<ParamField query="has_images" type="boolean">
  Filter to trades that have (or lack) uploaded images. Example: `true`
</ParamField>

<ParamField query="page" type="integer">
  Page number, starting at `1`. Example: `1`
</ParamField>

<ParamField query="limit" type="integer">
  Results per page, between `1` and `200` (default `50`). Example: `50`
</ParamField>
