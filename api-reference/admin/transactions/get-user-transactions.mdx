---
title: "Get User Transactions"
---

<Warning>
  This endpoint is no longer part of the console API. To see a user's gift card trades, use `GET /console/giftcards/trades` with the `search` query set to the user's email, name, username, or reference (requires the `giftcards.read` ability). For a user's overall activity, the user endpoints expose their ledger, swaps, withdrawals, deposits, and transactions under `GET /console/users/{user}/...` (requires the `users.read` or `users.manage` ability).
</Warning>
