---
title: "Reject Trade"
api: "POST /console/giftcards/trades/{id}/reject"
---

## How it works

Rejects a pending or processing gift card trade, marks it `rejected`, and reverses the associated wallet transaction. A trade that is already processed returns `409`. Requires a staff bearer token with the `giftcards.manage` ability. Requests without it return `403`.

## Path parameters

<ParamField path="id" type="string" required>
  Gift card trade id. Example: `352`
</ParamField>

## Body

<ParamField body="admin_comments" type="string">
  Optional rejection note. Max 2000 characters. Defaults to `Rejected.` when omitted. Example: `Card already redeemed`
</ParamField>
