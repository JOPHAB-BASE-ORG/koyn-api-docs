Console endpoints used by Koyn staff. Every route lives under the `/console` base path.

Except for login and password-reset requests, each route requires a staff bearer token obtained from console login and passed as `Authorization: Bearer <token>`. Console tokens are short-lived. Beyond authentication, most routes are gated by a per-route staff ability (for example `withdrawals.manage` or `kycs.manage`); the required ability is noted on each page, and admins have full access. Responses use the standard `{ success, message, data }` envelope. See [Authentication](/guides/authentication), [Environments](/guides/environments) and [Responses](/guides/responses).

<Note>
  Example payloads are captured responses with personal data masked. Confirm each page against the current Laravel routes before relying on it.
</Note>
