---
title: "Reconciliation create"
api: "POST /console/reconciliations/create"
---

## How it works

Manually credits or debits a user's wallet to reconcile a discrepancy, records a reconciliation entry, and returns it with the resulting wallet transaction. The target must be a regular user, not an administrative account, and a debit cannot exceed the user's wallet balance. Requires a staff bearer token with the `reconciliations.manage` ability. Requests without it return `403`.

## Body

<ParamField body="user_id" type="string" required>
  Id of the user whose wallet is adjusted. Must be a non-administrative account. Example: `62`
</ParamField>

<ParamField body="amount" type="number" required>
  Amount to credit or debit. A debit cannot exceed the user's wallet balance. Example: `1000`
</ParamField>

<ParamField body="entry" type="string" required>
  Direction of the adjustment: `credit` or `debit`. Example: `debit`
</ParamField>

<ParamField body="reason" type="string" required>
  Internal reason for the adjustment. Max 150 characters. Example: `Resolve failed withdraw`
</ParamField>

<ParamField body="narration" type="string" required>
  Narration shown on the wallet transaction. Max 50 characters. Example: `hey fella money reversed`
</ParamField>

<ParamField body="transaction_id" type="string">
  Optional id of an existing wallet transaction to link; it must belong to the same user.
</ParamField>
